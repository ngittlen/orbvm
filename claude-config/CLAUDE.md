# Comments and prose

**Write the present, not the history.** State what the code does and why it must, in present tense. No change narrative — a comment is not a changelog. Ban "used to", "now", "as before", "previously", "recently hardened", "the race this fixes", "the review found". The reader has no memory of a prior version, a past bug, or a review; if the reason a guard exists matters, state the reason itself, not that it was once absent.
